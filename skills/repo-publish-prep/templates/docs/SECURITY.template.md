# Security Policy

## Supported Versions

We actively maintain and provide security patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of {{PROJECT_NAME}} seriously. If you suspect or find a security vulnerability, please do NOT create a public GitHub issue.

Instead, please report the vulnerability privately via one of the following channels:

- **GitHub Private Vulnerability Reporting:** Use the "Report a vulnerability" button under the **Security** tab of this repository.
- **Email Contact:** Send details to `{{SECURITY_EMAIL}}`.

### What to Include in Your Report

To help us triage and resolve the issue quickly, please include:
- A clear description of the vulnerability and potential impact.
- Step-by-step instructions or a minimal Proof of Concept (PoC) to reproduce the issue safely.
- Any suggested remediations or mitigations.

### Response Timeline

- **Initial Acknowledgment:** Within 48 hours of receipt.
- **Assessment & Status Update:** Within 5 business days.
- **Remediation & Advisory:** Once verified, a patch will be prepared and published alongside a security advisory acknowledging your contribution (unless you prefer to remain anonymous).
